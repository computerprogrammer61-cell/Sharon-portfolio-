# Sharon — Personal Portfolio

A responsive, dark futuristic personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — layout, colors, typography and responsive styles
- `script.js` — mobile navigation and current year

## Run locally
Open `index.html` in a web browser.

## Before publishing
1. Replace `hello@example.com` in `script.js` with Sharon's real contact email.
2. Edit the About, Skills and Projects sections in `index.html` so they accurately describe Sharon.
3. Add real project details as work is completed.

## Publish with GitHub Pages
Upload the contents of this folder to the root of a GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
